# Estate Cinema

A cinematic landing-page concept for presenting real-estate listing films. This repository contains a static marketing interface, a second visual version, and supporting media.

**Stage:** presentation prototype. A marketing page is not evidence of active client service, completed orders, or business results.

## Preview locally

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

Open http://127.0.0.1:4180. Review third-party destinations and media rights before republishing. This documentation does not grant a new license to the included media.
